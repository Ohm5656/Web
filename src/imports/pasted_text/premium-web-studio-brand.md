Create a premium multi-page website for a web design and website development service brand in Thailand.

This should NOT feel like a generic corporate website or a simple landing page.  
It should feel like a high-end creative web studio website that is visually impressive, modern, premium, trustworthy, and clearly more refined than typical website agency websites in the Thai market.

The site should be designed with a strong visual-first approach:
- minimal text
- high visual impact
- premium spacing
- beautiful image-based storytelling
- elegant UI cards
- soft but polished animation
- strong first impression
- highly user-friendly
- responsive on all devices
- fast-loading
- SEO-friendly structure

## Main design goals
The website must make visitors instantly feel:
- this brand is highly professional
- this brand has strong design taste
- this brand creates beautiful websites
- this brand is different from common market competitors
- the website is modern, premium, soft, clean, and trustworthy

## Color direction
- clean white base
- navy blue as the main accent color
- optional soft light neutral highlights
- avoid overly dark heavy visuals
- avoid childish or overly sweet colors
- keep the overall tone bright, clean, airy, premium, and contemporary

## Visual style
- minimal text, image-driven layout
- premium modern creative studio aesthetic
- rounded corners
- soft elegant shadows
- subtle glassmorphism where appropriate
- layered composition
- refined spacing
- editorial-style section layout
- motion must feel expensive and smooth
- every section should feel art directed, not templated

## Motion and interaction style
Use premium but lightweight motion:
- smooth scroll
- reveal on scroll
- subtle parallax
- floating motion
- elegant hover states
- layered transitions
- image reveal
- interactive portfolio mockups
All animations must enhance quality and professionalism without hurting performance.

## Website structure
Build the website as a multi-page premium service website, not a single-page only site.

Required pages:
- Home
- Portfolio
- Packages / Pricing
- Services
- About
- Contact

Optional expandable service pages:
- Company Website
- Corporate Website
- E-commerce Website
- Landing Page
- Portfolio Website
- Web App

## Home page sections

### 1. Hero Section
Design a highly visual premium hero section.

Requirements:
- large visual composition
- minimal text
- strong first impression
- headline: “บริการออกแบบและจัดทำเว็บไซต์”
- two CTA buttons:
  - ดูแพ็กเกจ
  - ดูผลงาน

Hero visual direction:
- use a refined premium composition related to website design
- can include website mockups, floating UI cards, abstract premium shapes, layered frames, or elegant device compositions
- should immediately communicate web design expertise
- should feel premium, modern, unique, and scroll-stopping
- the hero must make users want to continue exploring the page

### 2. Services Section
Design this section as visual icon buttons or premium service chips, not text-heavy blocks.

Service examples:
- เว็บไซต์บริษัท
- เว็บไซต์องค์กร
- เว็บไซต์ขายของออนไลน์
- เว็บไซต์ร้านอาหาร
- เว็บไซต์โรงแรม
- Landing Page
- Portfolio
- Web App

Design direction:
- each service is shown as a clickable premium icon card, chip, or pill button
- hover effects should be elegant
- layout should feel dynamic and interesting
- not like a standard corporate icon grid
- highly visual and easy to scan

### 3. Package Preview Section
Create 3 premium package cards.

Requirements:
- clearly differentiated package hierarchy
- space for package name
- space for starting price
- space for short feature list
- CTA button on each card
- center package may be slightly emphasized
- strong premium look
- not cluttered
- modern and eye-catching

### 4. Portfolio Preview Section
This is one of the most important sections.

Design a premium interactive portfolio showcase using:
- desktop monitor mockups
- mobile phone mockups
- website previews inside each device

Interaction requirement:
When users hover over the desktop mockup, the website screenshot inside the monitor should smoothly scroll downward, as if previewing the full webpage.
When users interact with or swipe past the mobile mockup, the website preview inside the phone should also move/scroll naturally.
This interaction should feel premium, smooth, realistic, and highly engaging.

Important:
- the scrolling should happen INSIDE the mockup frame only
- not the whole page
- make it feel like users are previewing real client websites
- use this as a signature interaction for the portfolio section
- keep performance optimized

Portfolio design direction:
- large visual cards
- elegant layered gallery
- premium hover motion
- minimal text
- each work only needs a short name or short category
- make users want to click and explore more

### 5. Why Choose Us Section
Use short visual cards only.

Topics to communicate:
- ดีไซน์สวยและแตกต่าง
- รองรับมือถือ
- โหลดไว
- SEO-friendly
- ดูแลต่อได้
- ใช้งานง่าย

Format:
- icon + short title
- very short supporting text
- clean layout
- easy to scan
- no long paragraphs

### 6. Final CTA Section
Design a strong but elegant closing section.

Short confident message examples:
- พร้อมมีเว็บไซต์ที่ดูดีและน่าเชื่อถือ?
- เริ่มต้นออกแบบเว็บไซต์ของคุณวันนี้

Buttons:
- ดูแพ็กเกจ
- ติดต่อสอบถาม

## Floating contact button
Add a floating contact button at the bottom-right corner of the website.

When clicked, it should reveal:
- Line
- Phone number
- Gmail / email

Design direction:
- premium floating action button
- clean expandable mini menu
- easy to use on desktop and mobile
- not intrusive
- elegant motion

## SEO requirements
Use SEO-friendly HTML structure.
Make the website structure suitable for ranking around these search intents:
- รับทำเว็บไซต์
- ออกแบบเว็บไซต์
- จัดทำเว็บไซต์
- เว็บไซต์บริษัท
- เว็บไซต์ขายของออนไลน์

Use a clear H1 in the hero.
Create proper title and meta description structure.
Do not stuff keywords unnaturally.

## Performance requirements
- lightweight motion
- fast loading
- optimized interaction
- mobile-friendly
- responsive on all devices
- clean layout at every screen size
- no clutter
- no heavy effects that slow down the site

## Avoid
- generic corporate website look
- too much text
- rigid layouts
- boring template sections
- dark heavy visuals
- childish or overly playful design
- stock-photo business scenes

A premium, multi-page, highly visual website for a web design service brand that feels elegant, modern, image-driven, interactive, professional, and clearly above standard market competitors.
